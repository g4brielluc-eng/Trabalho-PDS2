Detailed Description

Representa uma ordem de serviço da oficina mecânica.

A classe OrdemDeServico armazena as informações relacionadas à execução de um serviço, incluindo o veículo, os serviços solicitados, as peças utilizadas, o mecânico responsável, o diagnóstico e o status da ordem.

A ordem é criada com o status ABERTA.
