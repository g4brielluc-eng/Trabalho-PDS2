\doxysubsection{Detailed Description}
Representa um mecânico da oficina. 

Os métodos que recebem uma \doxylink{class_ordem_de_servico}{Ordem\+De\+Servico} exigem que ela esteja atribuída a este mecânico; caso contrário, lançam std::\+logic\+\_\+error.
